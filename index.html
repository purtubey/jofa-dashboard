Resumen de Mortalidad

Los datos de mortalidad se calculan a partir de los KPIs de cada sitio productivo. La mortalidad pre-destete proviene de Sitio 1 (maternidad), la mortalidad de engorde de Sitio 3 (terminacion), y la mortalidad de hembras del inventario reproductivo.

Benchmark Argentina: Pre-destete menor a 10% | Engorde menor a 3% | Hembras menor a 8% anual

Datos y Consolidacion

Los datos de Agriness S4 se consolidan diariamente entre las 01:00 y 07:00 (GMT-3). Los KPIs reflejan la informacion disponible hasta la ultima consolidacion completada.

Para datos en tiempo real de eventos individuales (servicios, partos, destetes), se consultan los endpoints de listado que reflejan los registros ingresados al sistema.

Variables de Entorno (Netlify)

El proxy de Netlify Functions requiere las siguientes variables de entorno configuradas en el panel de Netlify:

WSO2_API_KEYAPI Key del gateway WSO2 (Dev Portal > Applications > Production)
S4_USERNAMEEmail del usuario con acceso a la granja JOFA
S4_PASSWORDContraseña del usuario S4

WSO2_API_KEY se obtiene del Dev Portal (am.agriness.com:9443/devportal). Las credenciales S4 son las mismas que se usan para ingresar a S4 Farm.
